# RELI3023: Digital Religion #
## Welcome ##
This repository is for files for the course _RELI3023: Digital Religion_. It will include the syllabus, grading rubrics, and other material that we may find useful during the course.
### Our Core Method ###
Our core methodological approach is Critical Religious Literacy. While we delve into elements of it over the span of the course, the [introductory two pager](CRL_Two_Pager.pdf) is a good reference.
### A Note on GenAI ###
As a reminder, I have strong reservations about the use of GenAI and have written them up on the [this post on Medium](https://islamoyankee.medium.com/extended-ai-policy-661379761fc2).
